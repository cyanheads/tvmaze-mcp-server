# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-09-20

Publishes the public hosted endpoint at https://tvmaze.caseyjhand.com/mcp as a streamable-http remote in server.json, documented in the README.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-09-19

First published release — seven tvmaze_* tools over the keyless TVmaze API: title and external-id resolution, show profiles, episode guides, daily broadcast and streaming schedules, and credits.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-19

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
