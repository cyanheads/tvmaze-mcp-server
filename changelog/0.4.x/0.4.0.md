# 0.4.0 — 2026-11-10

## Added

- **TVmaze guide** is available at `skill://tvmaze-guide/SKILL.md` through the MCP Skills extension and the `skill://{+path}` resource template. The guide ships with plugin, npm, Docker, and MCPB installs.
- **Person credits** include season, episode number, and airdate on guest credits, and show premiere, end date, and status on cast and crew credits when available ([#24](https://github.com/cyanheads/tvmaze-mcp-server/issues/24)).
- **Episodes** include TVmaze's optional `airdate` programming or release date alongside the viewer's local date where known ([#26](https://github.com/cyanheads/tvmaze-mcp-server/issues/26)).

## Changed

- **Packaging** adds Agent Plugins manifests and keeps development files out of the MCPB. **Bun** now requires 1.4.4 or later. The JWT example documents issuer and audience settings.
- **Markdown links and images** use the framework's destination escaping.

## Fixed

- **Show, season, and schedule metadata** retain both recorded carriers. Linear schedule entries and show profiles prefer the network. Schedule filtering matches either carrier and returns each episode once ([#23](https://github.com/cyanheads/tvmaze-mcp-server/issues/23)).
- **Schedule channel misses** suggest calls for omitted feeds with the effective date, timezone, and channel ([#25](https://github.com/cyanheads/tvmaze-mcp-server/issues/25)).
