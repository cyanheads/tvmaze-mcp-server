# 0.1.1 — 2026-09-19

First published release. Television data from TVmaze over stdio or Streamable HTTP, built on [@cyanheads/mcp-ts-core](https://www.npmjs.com/package/@cyanheads/mcp-ts-core).

## Added

- **`tvmaze_search_shows`** — fuzzy title search, hard-capped at ten rows by the source with no pagination. Enrichment echoes the query and reports `shown` / `cap`; a saturated or empty result carries a notice routing to a narrower title or to `tvmaze_lookup_show`.
- **`tvmaze_lookup_show`** — resolve an `imdb`, `thetvdb`, or `tvrage` id to a TVmaze show. An id TVmaze does not carry comes back as `found: false` with `guidance`, not an error.
- **`tvmaze_get_show`** — full profile for one show id: `schedule_days` / `schedule_time`, `official_site`, `externals`, every season, and the `next_episode` / `previous_episode` the source has.
- **`tvmaze_get_next_episode`** — next air time by TVmaze id or by title, the title arm resolved through a stricter single-match search. A series between seasons is a `no_scheduled_episode` miss that still returns `previous_episode`.
- **`tvmaze_get_episodes`** — one season or the whole run, cursor-paged at `limit` 1–250 (default 50). Specials are excluded unless `include_specials` is set, and `season_not_found` names the seasons that do exist.
- **`tvmaze_get_schedule`** — episodes airing on a date, across one country's linear feed, the streaming feed, or all three merged, deduped, and sorted by `airstamp`. `applied_feeds` names which feeds answered; a feed that fails degrades to a notice rather than failing the call.
- **`tvmaze_get_cast`** — a show's main cast with character names and optional crew, or one episode's guest cast. Cast credits carry `as_self` and `voice_only`, crew credits `credit_type`.
- **`TvmazeService`** — the single upstream boundary. Requests are paced under TVmaze's documented per-IP budget with bounded concurrency and a 429 cooldown honoring `Retry-After`, retried outside the pacer so every attempt is re-paced, in front of a size-bounded TTL response cache shared across tenants.
- **Contributor-authored summaries arrive as plain text** — tags removed, control characters dropped, and the `<` of any element entity decoding reconstructs stripped, so an encoded `&lt;script&gt;` never reaches a client as live markup. The prose itself is never rewritten.
- **Air times derive from `airstamp` alone**, rendered into a caller-supplied IANA timezone. A record with no announced broadcast time reports `time_known: false` and omits `local_time`; absent upstream fields render as `Not available` rather than `0` or `""`.
- **Seven optional `TVMAZE_*` variables** — `TVMAZE_BASE_URL`, `TVMAZE_USER_AGENT`, `TVMAZE_DEFAULT_TIMEZONE`, `TVMAZE_DEFAULT_COUNTRY`, `TVMAZE_CACHE_TTL_S`, `TVMAZE_MAX_CONCURRENCY`, `TVMAZE_REQUEST_TIMEOUT_MS`. TVmaze needs no account or key, so the server runs with nothing set.
- **Data terms** — TVmaze data is licensed CC BY-SA. Every show, episode, and person record carries a `url`, and keeping it is what satisfies attribution; ShareAlike binds an adaptation to the same licence.
