# 0.2.0 — 2026-09-22

## Added

- **`tvmaze_get_episodes` `air_date`** — lists the episodes the source dates to one day via `/episodesbydate`, the direct path to a single night of a daily show; mutually exclusive with `season`. Fails as `invalid_date` on a non-calendar date. (#12)
- **`tvmaze_get_cast` episode `include_crew`** — an episode's guest crew (director, writer) from one embedded request; joins the same paged sequence as guest cast. (#11)

## Changed

- **Breaking: `tvmaze_get_cast` now pages.** Both scopes take `limit` (default 50, max 250) and `cursor`; cast and crew page as one sequence, split back into `cast`/`crew` per page, with `cast_total`/`crew_total`, `has_more`, and `next_cursor`. A caller reading the full list in one response must now follow `next_cursor`. (#3)
- **Breaking: `tvmaze_get_schedule` rows carry a compact show reference** (`id`, `name`, `url`, `type`, `channel`, `channel_type`, `channel_country`, `genres`) instead of the full show profile — synopsis, externals, image, rating, and runtimes are gone from `entries[].show`. Call `tvmaze_get_show` with the id for the full profile. (#10)
- **`limit` now sets the page size on every call**, including one that passes `cursor` — `tvmaze_get_episodes` and `tvmaze_get_schedule` previously took the size back out of the cursor, freezing the first call's `limit`; `cap` now reports what was actually applied. Cursors issued before this release keep working. (#8)

## Fixed

- **Whole-run `tvmaze_get_episodes` now counts omitted specials**, matching the season arm — both request `?specials=1` and filter locally. (#5)
- **A `|` in a season name or channel no longer shifts the season table's columns** — escaped before it enters the Markdown row; `structuredContent` is unaffected. (#4)
- **`Episode.local_date`'s description now matches its behavior** — the requested-timezone date when `time_known` is true, the source's own announced date otherwise, never timezone-converted. (#6)
- **`tvmaze_get_next_episode`'s miss headline follows `miss_reason`** — a title that resolved to no show now renders "Show not found" in `content[]` instead of "No scheduled episode". (#9)

## Dependencies

- `@types/node` `26.6.1 → 26.6.2`
